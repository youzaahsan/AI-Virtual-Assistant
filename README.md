### 💼 Project Category

**AI-Powered Virtual Assistant & Smart Automation Platform**

---

### 📝 Project Description

A futuristic AI-powered virtual assistant inspired by JARVIS, built to provide conversational AI, voice interaction, system monitoring, automation commands, camera access, image generation, and personalized assistant controls.

---

### 🛠️ Technologies Used

- React 19
- TypeScript
- Vite
- Node.js
- Express.js
- Google Gemini AI
- Motion
- Lucide React
- Tailwind CSS
- Web Speech API
- Browser Speech Synthesis
- LocalStorage

---

### ✨ Main Features

- 🤖 **AI Chat Assistant** — Gemini-powered conversational assistant
- 🎙️ **Voice Commands** — Speech recognition and voice interaction
- 🔊 **Text-to-Speech** — AI responses can be spoken aloud
- 🖥️ **System HUD** — Futuristic system monitoring interface
- 📊 **System Telemetry** — CPU, RAM, temperature, internet speed and uptime
- 🌦️ **Weather & News** — Server-side weather/news integration
- 📷 **Camera HUD** — Webcam-based interface scanner
- 🖼️ **AI Image Generation** — Generate visuals through AI
- 🌐 **Web Automation** — Open websites and perform searches
- 🎵 **Music Commands** — Voice-controlled music actions
- ⚙️ **Custom Commands** — Create personalized assistant commands
- 🎨 **Theme Customization** — Cyan, red and orange themes
- 🔐 **Passcode Authentication** — Protected assistant access
- 💾 **Local Persistence** — Saves preferences and chat history
- 🐍 **Python File HUD** — View and interact with Python files
- ⚡ **Animated Interface** — Motion-powered futuristic UI

### 🏗️ Project Architecture

- **App.tsx** → Main AI assistant interface
- **main.tsx** → React application entry point
- **index.css** → Global styling and visual design
- **pythonFiles.ts** → Python file-related functionality
- **types.ts** → TypeScript type definitions
- **server.ts** → Server-side functionality and API handling
- **metadata.json** → Application metadata
- **.env.example** → Environment variable configuration
- **vite.config.ts** → Vite configuration
- **tsconfig.json** → TypeScript configuration
- **package.json** → Dependencies and project scripts
